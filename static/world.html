World inspector

Every world is generated from a seed: a causal DAG drawn from an anonymised template, or two templates bridged into a compound. The agent surface and the observer truth are shown separately below — the separation on this page is the same one the code enforces.

Agent surface

everything the agent is allowed to know

Observer truth

never shown to the agent — analysis and humans only

Public on purpose: any reader of the public repo can compute this from the seed. The benchmark's boundary is process-level — nothing on the agent's path calls this endpoint — and anonymisation guards against retrieval from training, not against a person reading the answer.
