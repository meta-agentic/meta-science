Variable atlas

never shown to the agent — families and parameters are the hidden truth

One card per variable. The shape does the identification: a bell is a gaussian source, a straight line a linear response, a power curve a multiplicative one, a blow-up an exponential, an S a saturating response. Curves are drawn from each variable's actual parameters, and each family shares one scale across its cards — a narrow sigma is a tall spike, a steep slope is visibly steeper — so cards compare against each other, not only against their own box. Multi-parent mechanisms run the curve along one parent: the strongest for additive families, and for multiplicative the exponent farthest from 1, since x^0.95 would draw as a straight line and defeat recognition by silhouette.

Truth is public on purpose: any reader of the public repo can compute it from the seed, so secrecy is not what protects the benchmark. The boundary is process-level — nothing on the agent's path calls the truth endpoint — and anonymisation guards against retrieval from training, not against a person reading the answer. ← demo · the evidence
